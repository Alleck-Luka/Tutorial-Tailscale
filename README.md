# Tutorial vpn Tailscale

Pra expor o servidor pra vocês, estou usando o software **Tailscale**. É bem parecido com outros vpns (Hamachi, RadminVPN etc.), exceto que esse tem rodado bem liso.

### Passo 1 - Baixar e configurar o Tailscale

Visite o site oficial do Tailscale:

https://tailscale.com

![Imagem 1](https://github.com/Alleck-Luka/Tutorial-Tailscale/blob/main/Pasted%20image%2020260426161945.png)

Nele você consegue baixar o Tailscale desktop, e logar ou criar sua conta. Faça essas duas coisas.
Após isso, siga os tutoriais do próprio Tailscale pra conectar o seu computador com a sua conta Tailscale.

### Passo 2 - Obter acesso à maquina host

Aqui é preciso que você peça um link de share meu. Por segurança, eu vou gerar um link de acesso único na hora. Após receber o link, é só usar no navegador (é necessário estar logado na sua conta no navegador).

### Passo 3 - Conectar no jogo

A esse ponto você deve saber que o Tailscale fica na trail da barra de tarefas (A setinha pra cima).
Se você clicar com o botão direito em cima dele, você consegue ver as opções do aplicativo.

![https://github.com/Alleck-Luka/Tutorial-Tailscale/blob/main/Pasted%20image%2020260426161945.png](https://github.com/Alleck-Luka/Tutorial-Tailscale/blob/main/Pasted%20image%2020260426162240.png)

Em network devices, os dispositivos que você conectou à sua conta vão aparecer dentro de My devices. Já as máquinas compartilhadas com você, assim como aquelas que estão dentro de redes da qual você faz parte (existe também convite de redes inteiras ao invés de somente determinada máquina).

Dependendo do jogo, o servidor pode aparecer em Lan, ou precisar de conexão direta. Caso aparecer em Lan, é só conectar e pronto. Caso seja conexão direta, você vai pegar o ip do computador hóspede dentro dessa janela, e inserir no local indicado pelo jogo (lembrando que geralmente o jogo também vai pedir um numero de porta, que você vai precisar pegar com o admin do servidor).
